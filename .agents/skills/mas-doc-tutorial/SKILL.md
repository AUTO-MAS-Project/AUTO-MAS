# MAS 文档教程

产出供文档站维护者审阅的操作教程、真实截图和逐主题验证记录。完成时，每篇采用的教程都能追溯到软件版本与实际运行，文字、步骤和截图一致，用户能查看效果；失败主题有明确记录，原有确认产物保持完整。

本 Skill 编排 Agent 的工作，复用主仓 E2E；它没有独立 CLI、MCP 服务或预装教程目录。Codex 与 DeepSeek Harness 共用此文件，不依赖某个宿主专有的浏览器工具。宿主未发现 Skill 时，显式读取本文件后执行；自动发现与实际加载情况分别核验。

## 范围与授权

根据用户要求读取源码和文档、建立隔离演示数据、运行本地浏览器流程、编辑指定教程并展示预览。提交、推送或发布沿用本次对话已有授权与仓库贡献规范，生成教程本身不授予发布权限。真实账号、游戏执行和外部通知不属于默认的教程采集范围。

## 明确本批次

- 列出主题、目标文章与语言、应用源码位置、文档仓库位置和适用版本。沿用用户指定的版本；未指定时先核对文章版本和发布记录，说明选用的基线。开发分支画面标为草稿，不直接替换发行版教程。
- 对每篇定义读者要完成的操作、初始演示数据、截图步骤和最终可观察结果。保留原文仍有效的业务解释，只修订本次操作章节。
- 编写或执行流程前读取 [采集与交付](references/capture-workflow.md)。需要了解已验证效果与限制时读取 [首批试验](references/validated-pilot.md)。

## 验证后采用

使用 [mas-e2e](../mas-e2e/SKILL.md) 的隔离启动入口。首次创作先探索真实页面，再把动作、等待与结果断言写入可重跑的 Playwright 流程；已有流程先检查版本和定位器再复用。每个主题单独启动隔离环境，串行执行，避免前一主题的数据改变后一主题的初始状态。

截图使用演示账号与占位收件人。参数说明以当前 UI 和对应版本的配置、调度或通知实现共同核对；配置保存通过不等于游戏执行或消息送达。保存后刷新并回读关键值，再确认截图对应的状态。

产物先写入本批次的新目录。只有流程确实执行、断言通过、截图完整且可读的主题才进入文档候选修改。逐篇记录通过、失败或未执行，失败后可继续其他独立主题；保留诊断材料，不把半成品覆盖到上次确认的文章和图片。定位器或断言失效时修正流程或报告失败，不靠弱化断言、隐藏错误或改写说明把失败变成成功。

## 图文与预览

将通过主题整理为前置条件、操作步骤、截图及必要注意事项。区分点击入口、配置已保存和最终业务结果；功能之间可能叠加的触发条件要核对。声明适用版本、实际制作的 Agent 和演示范围，不把不同宿主的产物统一署名为 Codex。

核对文档仓库的图片约定、原图链接和侧栏；同步本次涉及的中英文操作说明，截图语言与正文语言不同时说明。构建文档并打开实际页面，检查图像加载、章节链接、移动端溢出和文字与画面的对应关系。展示新旧图或关键差异，让用户能从预览进入完整章节。

批次开始时说明范围与基线；运行中报告已通过和失败的主题。结束时提供文章与预览位置、主题结果、运行命令及退出结果、来源记录、图文差异和未验证范围。需要 PR 时关联实际产物与验证证据；既往成功案例只作为参考，不代替本批次验证。
