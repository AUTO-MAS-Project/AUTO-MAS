# 神秘小功能

此目录保存神秘入口的设备与当前源码指纹。Token 获取复用现有社区登录接口，
请求与响应结构仍放在 `app/models/schema.py`，HTTP 入口仍放在 `app/api/`。

前端入口位于「设置 → 功能设置」底部右侧。密钥仅供本地轻量解锁，入口提供可复制的申请信息，
不展示发码算法。解锁后可主动重新锁定，仍在北京时间零点自动锁回。

## 8 位密钥协议

- `deviceHash`：有效的 Windows SMBIOS UUID 统一为小写标准格式，对
  `auto-mas:mystery:device:v1|smbios|<UUID>` 的 UTF-8 字节计算 SHA-256。
  空值、全零、全 F 或读取失败均阻止申请，不退回共用标识。
- `backendHash`：以实际运行后端的源码根目录为准，包含 `main.py` 和 `app/**/*.py`，排除
  `__pycache__`。按相对路径排序，路径使用 `/`，源码 CRLF 统一为 LF；每个文件先计算
  SHA-256，再按 `相对路径 + NUL + 小写文件哈希 + LF` 追加到清单。
  整体 SHA-256 的首段为 `auto-mas:mystery:backend:v1\n`。不包含配置、日志、资源或依赖环境。
- 申请信息是 `{"version":1,"deviceHash":"...","backendHash":"..."}`。两项指纹在后端进程内
  共用缓存，重启后重新采集；前端在主连接重连后重新获取。
- 原文为 `mystery-v1|<deviceHash>|<backendHash>|<issuedAt>`，其中 `issuedAt` 是十进制 UTC
  Unix 秒时间戳。对原文的 UTF-8 字节计算 SHA-256，取前 6 字节，以无填充 Base64URL 编码，
  得到区分大小写的 8 位密钥。
- Electron 主进程在用户提交时尝试当前秒至前 1799 秒，完整匹配后再检查时间没有过期。
  不接受未来签发时间，也不接受旧的每日十六进制口令或其子串。
- 30 分钟仅限制输入密钥的有效期；成功解锁的状态保存北京时间日期和两项指纹，仍保持零点锁回。
  旧的仅日期记录，以及复制到其他设备或不同源码版本的记录，需要重新解锁。

发码工具独立于应用仓库，使用上述协议生成密钥。该协议是可复算的轻量门槛，不承担身份认证，
本机时间修改也会影响有效期。

神秘入口首页展示功能卡片，点击「Token 获取」进入独立子页面。
子页面共用首页的每日解锁状态，直接访问同样需要解锁。

米游社、森空岛扫码登录及塔吉多账密登录的前端实现统一放在
`frontend/src/views/mystery/tokens/`。获取的凭据保存到用户选择的社区账号组，
普通社区页面只保留已有凭据录入。库街区凭据获取引导用户使用
[Better-MAS-Tools（BMT）](https://github.com/Lance0174/Better-MAS-Tools) 本体。
