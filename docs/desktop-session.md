# 桌面分身验收

## VM 验收

在 Windows x64 虚拟机中启动 AUTO-MAS，使用可丢弃的测试配置、测试账号和游戏安装。记录 Windows 版本、测试提交、托管类型和启动方式。展示结果时移除密码、账号名及本机路径。

1. 在「设置 → 桌面分身」选择受支持的 PC 托管或队列并打开预览。确认脚本在分身操作窗口时，主桌面的鼠标和焦点可独立使用。分别验证后台最小化和原生最小化，再从主 MAS 的调度页查看进度并停止任务。
2. 连接一个已存在的子会话。取消接管时确认原有应用仍在运行。确认接管后选择「仅断开」，确认本次派发的任务已停止、原有应用仍在运行，并验证主桌面按同名或同一路径清理进程时不会关闭它们。另测明确选择注销时的收尾。
3. 让一个会话运行终末地，再从另一个会话对同一安装目录触发更新。确认更新中止，游戏仍在运行。在三月七 PC 客户端模式下验证命令结束后，命令启动的游戏仍可供后续步骤使用。
4. 在允许修改系统设置的测试 VM 中，将远程桌面服务置为停止。确认环境修复成功时服务保留运行。另造一次复查失败，确认服务恢复为停止，启动类型和其余改动一并恢复。

环境检查或连接失败时，可从分身窗口导出日志。记录实际执行的场景和结果，跳过的 Windows 版别、专项或真实游戏流程单独注明。
