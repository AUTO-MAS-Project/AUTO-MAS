## AT-01：全新独立安装

**状态：`unverified`**

1. 验证 Full 便携 ZIP SHA-256 与同次发布的清单一致。
2. 选择新的空目录，例如专用 A 测目录；确认该目录不是 r6 安装目录，也不含稳定版用户数据。
3. 安装后确认可执行文件名为 `AUTO-MAS-v6-Experimental-Alpha.exe`，并记录实际安装路径。
4. 只观察首次窗口、安装/启动错误和日志；不要把它解释为正式稳定通过。
5. 检查 r6 原目录的文件、哈希与可启动性未被此安装流程改动。

需回传：安装路径截图、安装日志、Alpha/r6 目录对比、错误信息（若有）。

## AT-02：离线首次启动

**状态：`unverified`**

1. 使用新解压或复制出的 Alpha Full 目录；确认其中没有既有 `config`、`debug` 或 `logs` 运行时数据。
2. 在断网或已阻止出站的条件下，按 [OFFLINE_FIRST_START.md](OFFLINE_FIRST_START.md) 运行结构预检与人工启动辅助。
3. 在 UI 中完成首次初始化，并记录是否能看到首页、插件状态和明确错误。
4. 保留本次新生成的日志、配置文件名、端口占用信息和截图。
5. 结束后由执行者手动关闭应用；不允许用破坏性脚本清理测试目录。

需回传：预检输出、网络隔离证据、首页截图、日志尾部、配置文件清单。

## AT-03：r6 升级与回滚边界

**状态：`unverified`**

1. 先对 r6 用户数据创建可恢复副本，并记录原始路径与哈希；不要操作冻结 r6 发布目录。
2. 在隔离副本中验证 Alpha 对旧配置的导入/兼容行为，记录每个被迁移或新建的文件。
3. 关闭 Alpha 后确认 r6 副本仍可按原方式启动；如需回滚，恢复备份而非手工删除未知文件。
4. 记录任何配置字段丢失、明文泄漏、重复任务或无法恢复的情况。

需回传：前后文件清单与哈希、导入日志、回滚步骤、r6 副本启动结果。

## AT-04：插件加载与失败隔离

**状态：`unverified`**

1. 使用独立 Alpha 配置，分别加载一个预期正常的插件和一个可控失败样本。
2. 记录发现、配置读取、激活、失败提示、停用/恢复及重启后的状态。
3. 确认失败样本不会阻断主界面、其他插件或配置保存。
4. 不替换正式 wheelhouse；若使用本地样本，记录名称、版本、来源和 SHA-256。

需回传：插件清单、界面截图、后端日志、失败隔离过程和恢复结果。

## AT-05：MaaFW ProjectInterface 项目

**状态：`unverified`**

1. 在隔离数据目录导入一个有明确来源的 MaaFW 项目样本。
2. 检查 interface 解析、任务/预设显示、配置保存和预览或 dry-run 行为。
3. 不在未经授权的环境启动真实 Agent、游戏或模拟器；真实执行应另立记录。
4. 记录路径错误、资源缺失、版本不匹配和未知字段的提示。

需回传：项目版本/来源、导入日志、配置截图、预览或 dry-run 输出。

## AT-06：HSR、SRA、M7A 专项配置

**状态：`unverified`**

1. 在 Alpha 的 HSR 页面分别填写或导入 SRA、M7A 所需路径和培养目标相关配置。
2. 检查动态关卡/阶段或培养目标入口的可见性、保存和重启后的恢复。
3. 对每个引擎记录可用、不可用与错误提示；不要用静态 UI 显示替代实际执行结论。
4. 若进行真实脚本执行，须取得单独授权并保存完整日志。

需回传：各引擎版本/路径、配置前后截图、保存后文件差异、日志。

## AT-07：游戏与模拟器管理中心

**状态：`unverified`**

1. 在真实 Windows 环境检查游戏与模拟器管理入口、搜索/发现、编辑与错误提示。
2. 记录每种已安装或未安装模拟器的发现结果，保留版本、路径和日志。
3. 不把“发现到路径”视为“可稳定控制”；启动、连接、清理和异常恢复需分别记录。
4. 不得对用户主环境进行不可逆清理。

需回传：页面截图、搜索结果、日志、异常恢复结果。

## AT-08：签名与安装器信任状态

**状态：`unverified`**

1. 对解压后的 `AUTO-MAS-v6-Experimental-Alpha.exe` 运行 `Get-AuthenticodeSignature`。
2. 记录 `Status`、证书主体、时间戳（若有）及文件 SHA-256。
3. 若状态非 `Valid`，在测试反馈中明确标注未签名/签名无效/待定；不得声称已验证发布者。

需回传：完整 PowerShell 输出、两份文件哈希、SmartScreen/UAC 截图（如出现）。
