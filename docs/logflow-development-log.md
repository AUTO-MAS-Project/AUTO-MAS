### 延迟与反压采样

以 `1bc3b61b7` 在 Windows 本机重复三轮。每轮 4 个模拟脚本进程，各写 32 批 stdout，每批 32 行、每行 160 字节、批间隔 125 ms。每轮共接收 4,096 行、640 KiB，首末行的接收间隔约 3.89 秒，约 1,054 行/秒。前三个 worker 用普通规则，第 4 个 worker 的 sink 在首次写入时阻塞。以高精度单调时钟记原始行分发时间，宿主以 5 ms 为目标间隔用游标读取，读到节点时取样。事件循环延迟为该轮计划休眠时间之外的等待。

| 指标 | 三轮范围或峰值 |
| --- | --- |
| 正常节点可查询延迟 | p50 0.63–1.11 ms，p95 0.83–1.64 ms |
| 宿主事件循环额外等待 | p95 10.50–10.98 ms，最大 15.80 ms |
| 宿主待发队列峰值 | 正常会话各 32 帧／7,008 字节，阻塞会话 595 帧／130,305 字节 |
| 宿主及采集进程工作集 | 宿主峰值 48.48 MiB，4 个 worker 合计峰值 166.79 MiB |
| 收尾耗时 | 正常会话 21.80–26.68 ms，阻塞会话 301.94–324.24 ms（配置等待 300 ms） |

自定义 sink 在 worker 内同步消费，此场景没有独立 sink 队列。逐轮用进程等待确认 4 个 worker 均退出，收尾返回后的确认耗时不超过 3 ms。可查询延迟包含采样等待，范围限于宿主内存中的游标查询。
