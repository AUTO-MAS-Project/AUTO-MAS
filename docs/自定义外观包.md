# 自定义外观包

自定义外观包是一个 ZIP 文件，导入后保存在用户数据目录中，应用升级不会清除。
外观包只承载 JSON 和 PNG、JPEG、WebP 图片；不会执行 CSS、JavaScript、HTML 或 SVG，也不会加载网络资源。

```text
my-appearance.zip
├── theme.json
├── preview.png                 # 可选，设置页预览图
└── assets/
    ├── background.png          # 可选，背景图
    ├── mascot.webp             # 可选，角落装饰图
    ├── menu-home.png           # 可选，菜单图标（也可复用其他已声明图片）
    └── cursor-pointer.png      # 可选，PNG 光标（1..64px）
```

`theme.json` 的最小示例：

```json
{
  "formatVersion": 1,
  "id": "my-appearance",
  "name": "我的外观",
  "description": "一个暖色外观示例",
  "mode": "light",
  "tokens": {
    "colorPrimary": "#1677ff",
    "colorBgLayout": "#f5f7fb",
    "colorBgContainer": "#ffffff",
    "colorBgElevated": "#ffffff",
    "colorText": "#1f2937",
    "colorTextSecondary": "#667085",
    "colorBorder": "#d0d5dd",
    "colorBorderSecondary": "#eaecf0",
    "borderRadius": 8
  },
  "background": {
    "path": "assets/background.png",
    "opacity": 1,
    "surfaceOpacity": 0.72,
    "position": "right bottom",
    "size": "cover"
  },
  "mascot": {
    "path": "assets/mascot.webp",
    "width": 144,
    "opacity": 1,
    "position": "bottom-right"
  },
  "preview": "preview.png",
  "menuIcons": {
    "home": "assets/menu-home.png",
    "settings": "assets/menu-home.png"
  },
  "cursors": {
    "pointer": {
      "path": "assets/cursor-pointer.png",
      "hotspotX": 0,
      "hotspotY": 0
    }
  }
}
```

`id` 只能使用小写字母、数字、下划线和短横线。`tokens.colorPrimary` 必填，其他 token 和图片字段可省略。
资源路径必须指向 ZIP 内实际存在的图片；`background` 和 `mascot` 的资源必须放在 `assets/` 目录。
导入时会校验路径、图片格式、文件数量和大小。相同 ID 的包默认拒绝，确认替换后才会覆盖原包。

`background` 是铺在整个窗口底部的固定背景，包括标题栏和侧栏；切换页面、滚动内容时图片保持原位。
`opacity` 控制图片本身的不透明度，范围为 0 到 1，省略时为 1。
`surfaceOpacity` 控制前景布局和卡片表面的不透明度，范围为 0 到 1，省略时为 0.72；0 表示表面全透明，1 表示不透明。
文字、图标、按钮和输入框不会整体变透明；弹窗、抽屉和下拉菜单保持包内的不透明配色。
只有包内实际提供背景图片才启用透明表面，纯配色包和内置外观沿用正常背景。

`menuIcons` 是可选的菜单图标映射；每个值必须指向 ZIP 内 `assets/` 下的 PNG、JPEG 或 WebP 图片，未提供的键保留应用内置图标。建议使用透明图片，侧栏按 24px 显示。
支持的固定键为：`home`、`scripts`、`plans`、`emulators`、`queue`、`scheduler`、`gameSign`、`history`、`tools`、`settings`、`testRouter`、`ocrDev`、`overlayMaskDev`、`updateDownloadDev`。
同一图片路径可以被多个键复用，开发菜单键只在开发环境显示。

`cursors` 是可选的光标映射，仅支持 `default`、`pointer` 和 `text` 三个键。每个资源必须是 `assets/` 下的 PNG，图片宽高均须为 1 到 64 像素；`hotspotX` 和 `hotspotY` 为可选的非负整数，默认是 0，并且必须落在图片范围内。缺少某个键时继续使用浏览器原生光标。

角落装饰在主界面侧边留出空间，避免遮挡内容。窗口宽度不超过 800px 时隐藏装饰并恢复内容宽度。
初始化页面和独立日志窗口使用包内配色与背景，不显示角落装饰。
