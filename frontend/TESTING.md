# 前端核心测试

长期测试只保留便宜、稳定、能守住公共基础设施关键故障的用例。
单个页面、专项功能、展示文案和样式的回归测试用于本地验证，默认不入库；纯函数也不例外。

## 保留边界

| 边界 | 重点防止的问题 |
| --- | --- |
| 配置文件与保存队列 | 并发保存互相覆盖、写入失败卡住队列、损坏配置被覆盖、旧配置被错误重新导入 |
| WebSocket 与任务快照 | 重连状态错乱、关闭后旧请求复活连接、订阅串台、失败后无限请求 |
| Runtime 协议与后端生命周期 | 分片解析失败、握手不匹配、误判就绪、退出遗留后端、无法恢复启动备份 |
| 初始化与更新编排 | 未停机就更新、更新失败无法重试、取消后仍继续执行、退出时重启后端 |
| Runtime 文件更新 | 安装未经可信哈希验证的文件、并发替换、取消后替换、失败时破坏旧文件与备份 |
| 诊断包 | 混入其他专项的诊断目录、泄露凭据或用户主目录 |
| 全局词表 | 缺少词条、非法转义影响整张词表 |

## 新增与维护

- 新增长期用例前说明：守住什么公共边界、破坏后会造成什么关键故障、现有用例为何不能覆盖。
- 每个独立故障保留代表性用例，不按参数、页面、错误文案逐项堆叠。
- 测试调用实际被测模块，只替换网络、进程、IPC 等外部边界；不联网，不操作真实用户数据。
- 不读取源码断言绑定、函数体、样式或导入字符串；全局词表扫描等无法通过模块调用验证的公共契约除外。
- 删除用例时同步删除无引用的桩、夹具和说明，不通过 skip 或调整收集范围隐藏测试。
- E2E 主流程入口仍在 `e2e/`，与这组单元测试分别运行。

## 桌宠窗口 E2E

在 Windows 图形会话中运行 `yarn e2e --grep '@mascot'`。此流程会编译 Electron 主进程，
生成并导入独立的 v1 桌宠包，再通过真实窗口与 preload/IPC 验证点击、拖拽、播放、提醒及资源释放。
输出包含明暗主题截图、步骤结果和 HTML 报告；测试数据使用启动器创建的临时目录，不读取本机资源包或配置。

验证期间弹出的窗口由自动化控制，合成指针的位置与夹具中的系统光标读数同步，不适合同时手动拖动。
该流程不证明真实系统鼠标输入、跨屏 DPI 或游戏任务的运行结果；任务状态由夹具注入。

## 验证命令

在 `frontend/` 中使用 PowerShell 7 执行：

```powershell
yarn test
yarn lint --max-warnings 1
yarn typecheck
```

需要控制本机并发时使用 `yarn test --maxWorkers=4`。测试不代表真实安装包、模拟器或脚本运行验证。
