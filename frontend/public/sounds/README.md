# 按压音效文件

主页中心图标（星核）按压 / 松手时播放这里的声音。设置页「按压音效」里的内置音效组按下表取文件：

| 音效组 | 按下 | 松开 |
| --- | --- | --- |
| 小黄鸭 | `press-duck.mp3` | `press-duck-release.mp3` |
| 音效1 | `press-fx1.mp3` | `press-fx1-release.mp3` |

这几个文件没有随仓库分发。把音频按上面的名字放进本目录后重新构建即可发声；缺文件时对应音效静音，其余功能不受影响。

用户在设置页导入的自定义音频不走这里，它读的是本机文件路径。

选择「自定义音频」后，可用「同一音频」让按下和松开播放同一个文件，也可用「分别设置」为两个阶段选择不同文件。每个文件都可单独试听，「整组试听」会依次播放按下和松开的声音。
