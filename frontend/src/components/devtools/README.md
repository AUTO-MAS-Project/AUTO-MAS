# 开发工作台

同时满足开发构建与公共应用环境的 development 判定才加载；生产构建、常规 E2E 和独立辅助窗口不挂载工作台。

- 右下角 `DEV` 或 `Ctrl/Cmd + Shift + D` 打开，`Esc` 关闭。
- 概览：真实 HTTP / WebSocket 地址、连接重试与订阅数、应用环境、Electron 启动模式、退出时保留后端的策略、按需健康探测和诊断摘要。
- 存储：查看、搜索、编辑、格式化、复制和删除当前来源的 localStorage / sessionStorage；清空始终针对整个当前存储区，筛选不会改变删除范围。
- 路由：当前参数、已注册路由和会话历史；所有跳转仍经过正常守卫。
- 工具：Vue DevTools、组件源码定位、Chromium DevTools、主题切换及查询缓存概况。

编辑器切换条目、存储区、标签和关闭时保护未保存内容。保存前检测其他写入造成的冲突；刷新可重新读取同窗口写入的数据。
编辑浏览器存储不会同步修改磁盘上的 MAS 配置，应用状态可能需要重新加载才生效。

Vue 调试使用[官方 Vite 插件](https://devtools.vuejs.org/guide/vite-plugin)。插件与 `@vue/devtools-core` 固定为同一版本，升级时须一起验证共享事件入口。
`Alt + Shift + D` 切换官方面板；源码定位通过官方 inspector 在本地编辑器打开组件，`Esc` 取消拾取。

面板操作不新增产品遥测，不上传存储、路由参数、查询内容或诊断摘要。手动重连复用现有生命周期协调器，保留开发环境隔离。
采样与查询缓存监听随对应标签释放，健康检查只在显式操作时发起；会话历史仅在内存保留最近 30 条。
