# 正则指南

正则表达式（简称「正则」）是一种**描述文本模式**的工具，你可以把它想象成「高级的搜索功能」：

- 普通搜索：搜索 `任务完成`，只能找到完全包含这几个字的行
- 正则搜索：搜索 `任务.{2}`，可以找到 `任务完成`、`任务失败`、`任务结束` 等任意「任务」后跟两个字的行

在 AutoMas 中，正则用于以下字段：

- **匹配正则**（表达式模式）：过滤需要处理的行。**必填，留空则该规则不生效**
- **起始正则 / 结束正则**（多行聚合模式）：划定多行窗口的起始和结束
- **提取表达式**中的 `$()` 内部：从文本中提取内容（提取表达式的完整语法请参考「表达式指南」）

> 下方教程教的是**正则语法本身**，可直接用于匹配正则字段，也可放在 `$()` 内用于提取。

---

## 从一个例子开始

以绝区零一条龙日志为例：

```
[23:48:19.773] [operation.py 675] [INFO]: 指令[ 咖啡店 ] 执行成功 返回状态 无需运行
[23:48:05.363] [operation.py 677] [ERROR]: 指令[ 等待大世界画面 ] 执行失败 返回状态 未到达大世界
[23:48:24.715] [operation.py 675] [INFO]: 指令[ 体力刷本 ] 执行成功 返回状态 剩余电量 187
```

期望效果：只保留执行成功的指令，并提取出指令名称：

```
咖啡店
体力刷本
```

我的匹配正则可以写作：

```
指令\[.+?\] 执行成功
```

我的提取正则可以写作：

```
指令\[\s*(.+?)\s*\] 执行成功
```

各步正则的处理效果（以第一条日志为例）：

| 步骤                          | 处理结果                                                 |
| ----------------------------- | -------------------------------------------------------- |
| 匹配正则 `指令\[.+?\] 执行成功` | 命中该行（行中包含 `指令[ 咖啡店 ] 执行成功`）           |
| 提取正则 `(.+?)`              | 捕获组提取 `咖啡店`                                      |
| 第二条日志                     | 匹配正则未命中（是「执行失败」），整行跳过               |

其中 `\[` 和 `\]` 是转义后的方括号（方括号在正则中有特殊含义，要匹配字面方括号需要加 `\`），`(.+?)` 是捕获组，用来标记要提取的部分。

## 直接写文字

最简单的正则就是直接写你要找的文字：

```
任务完成
```

这会匹配所有包含「任务完成」四个字的行。

## 用 | 表示「或」

竖线 `|` 表示「或者」，可以同时匹配多个关键词：

```
任务完成|任务失败|任务结束
```

这会匹配含有「任务完成」**或**「任务失败」**或**「任务结束」的行。

> 注意：匹配关键字字段中的 `|` 也是「或」的语义，支持多关键字任一命中。但在 `$()` 内部，`|` 是正则本身的「或」，不会被当作换行运算符。

## 用 () 提取内容

圆括号 `()` 用来**提取**你感兴趣的部分。比如日志是：

```
一条龙任务执行: 1/4
```

你想提取进度数字 `1/4`，写提取正则：

```
任务执行: (\S+)
```

- `(\S+)` 表示「提取一段不含空格的文字」
- `\S` = 非空白字符，`+` = 一个或多个
- 结果：提取出 `1/4`

> 如果在提取表达式字段中使用，需用 `$()` 包裹：`$(任务执行: (\S+))`。
> 注意：提取表达式里**正则必须有捕获组 `()` 才会提取内容**，无捕获组返回空串。
> 想提取整段匹配可写成 `$((任务执行: \S+))`。详见「表达式指南」。

## 常用符号速查

### 匹配字符

| 符号  | 含义                 | 举例       | 匹配结果                  |
| ----- | -------------------- | ---------- | ------------------------- |
| `.`   | 任意一个字符（除换行） | `任.完成`  | `任务完成`、`任意完成`    |
| `\d`  | 任意一个数字         | `第\d次`   | `第3次`、`第8次`          |
| `\w`  | 字母、数字或下划线   | `\w+`      | `hello`、`v3.1` 中的 `v3` |
| `\s`  | 空格、制表符等空白   | `\s+`      | 连续空格                  |
| `\S`  | 非空白字符           | `\S+`      | 一段不含空格的文字        |

### 大写 = 反义

记住一个规律：**小写字母匹配某类字符，大写字母是反义**

- `\d`（数字） ↔ `\D`（非数字）
- `\w`（单词字符） ↔ `\W`（非单词字符）
- `\s`（空白） ↔ `\S`（非空白）

### 匹配次数

| 符号    | 含义        | 举例      | 匹配结果            |
| ------- | ----------- | --------- | ------------------- |
| `*`     | 0 次或多次  | `ab*`     | `a`、`ab`、`abbb`   |
| `+`     | 1 次或多次  | `\d+`     | `3`、`123`、`88`    |
| `?`     | 0 次或 1 次 | `colou?r` | `color`、`colour`   |
| `{n}`   | 恰好 n 次   | `\d{4}`   | `2026`              |
| `{n,m}` | n 到 m 次   | `\d{1,3}` | `5`、`42`、`999`    |

### 特殊位置

| 符号 | 含义     | 举例       | 说明                 |
| ---- | -------- | ---------- | -------------------- |
| `^`  | 行首     | `^任务`    | 行的开头是「任务」   |
| `$`  | 行尾     | `完成$`    | 行的结尾是「完成」   |
| `\b` | 单词边界 | `\bINFO\b` | 独立的 `INFO` 单词   |

### 方括号：选择一个

方括号 `[...]` 表示「匹配其中任意一个字符」：

| 写法     | 含义                | 举例                       |
| -------- | ------------------- | -------------------------- |
| `[abc]`  | a 或 b 或 c         | `[男女]` → `男` 或 `女`    |
| `[0-9]`  | 0 到 9 任意数字     | 等同于 `\d`                |
| `[a-z]`  | a 到 z 任意小写字母 |                            |
| `[^abc]` | **非** a、b、c      | `[^0-9]` → 非数字          |

> `^` 在方括号**里面**表示「非」，在方括号**外面**表示「行首」。

---

## 圆括号的两种用法

### 捕获组：提取内容

```
(\d+) 次
```

从 `运行 3 次` 中提取 `3`。括号里的内容会被提取出来。

### 非捕获组：只分组不提取

```
(?:完成|失败)
```

如果你想用 `|` 但不想提取，用 `(?:...)`。`?:` 告诉正则「只分组，不要提取」。

> 在提取表达式中，只有捕获组 `()` 的内容会被提取，非捕获组 `(?:...)` 不会。想给捕获组起名可用 `(?P<名字>...)`，多个命名组会一起返回。

---

## 转义特殊字符

如果匹配的文字里有正则特殊字符（`. * + ? ( ) [ ] { } | ^ $ \`），需要加 `\` 转义：

| 要匹配   | 正则写法    | 说明         |
| -------- | ----------- | ------------ |
| `3.14`   | `3\.14`     | `.` 要转义   |
| `[INFO]` | `\[INFO\]`  | `[]` 要转义  |
| `(1/4)`  | `\(1/4\)`   | `()` 要转义  |

## 实战：从真实游戏日志提取

> 以下示例全部来自真实的游戏辅助工具日志，你可以直接复制使用。

### 示例 1：提取版本号

**日志行**（MSBA 尘白禁区小助手）：

```
[2026-06-15 17:23:09,652][INFO][update.py][L1021][_init_run_context] | 当前版本: v3.1.27
```

期望效果：`v3.1.27`

| 输入框     | 值                       |
| ---------- | ------------------------ |
| 匹配正则   | `当前版本`               |
| 提取正则   | `当前版本:\s*(\S+)`      |

- `\s*` = 可能有空格（0 个或多个），兼容 `: v3.1.27` 和 `:v3.1.27`

### 示例 2：提取更新步骤

**日志行**（MSBA）：

```
[2026-06-15 17:23:09,652][INFO][update.py][L1222][_run_normal] | [步骤1] 开始检查更新...
```

期望效果：`[步骤1] 开始检查更新...`

| 输入框     | 值                          |
| ---------- | --------------------------- |
| 匹配正则   | `步骤\d`                    |
| 提取正则   | `(\[步骤\d\].+)`            |

- `\d` 匹配一个数字，所以 `步骤\d` 能匹配 `步骤1`、`步骤2`、`步骤3`...
- `\[` 和 `\]` 是转义后的方括号
- `.+` = 一个或多个任意字符

### 示例 3：提取窗口标题

**日志行**（MSBA）：

```
[2026-06-15 17:23:08,451][INFO][main_window.py][L2695][set_title] |  设置窗口标题：尘白禁区小助手 v3.1.27 管理员
```

期望效果：`尘白禁区小助手 v3.1.27 管理员`

| 输入框     | 值                  |
| ---------- | ------------------- |
| 匹配正则   | `窗口标题`          |
| 提取正则   | `窗口标题：(.+)`    |

- `.+` = 提取冒号后面的所有内容

### 示例 4：提取升级通知

**日志行**（ok-ef）：

```
2026-08-04 22:03:16.377  INFO            main ThreadId(01) pyappify_lib::utils::window: send_notification: 升级成功: ok-ef v1.0.14
```

期望效果：`ok-ef v1.0.14`

| 输入框     | 值                          |
| ---------- | --------------------------- |
| 匹配正则   | `升级成功`                  |
| 提取正则   | `升级成功:\s*(.+)`          |

### 示例 5：提取 OneDragon 启动信息

**日志行**（zzz-od）：

```
[15:03:56.651] [runtime_launcher.py 28] [INFO]: OneDragon 集成启动器 v2.5.1
```

期望效果：`v2.5.1`

| 输入框     | 值                       |
| ---------- | ------------------------ |
| 匹配正则   | `集成启动器`             |
| 提取正则   | `集成启动器\s+(\S+)`     |

- `\s+` = 一个或多个空格
- `(\S+)` = 提取版本号

### 示例 6：忽略大小写匹配错误

**日志行**（BetterGI）：

```
[18:01:51.026] [WRN] BetterGenshinImpact.GameTask.Common.TaskControl
当前获取焦点的窗口为: NTEGame，不是原神，暂停
```

期望效果：提取窗口名 `NTEGame`

| 输入框     | 值                              |
| ---------- | ------------------------------- |
| 匹配正则   | `(?i)wrn\|warn\|warning`        |
| 提取正则   | `窗口为:\s*([A-Za-z]+)`         |

- `(?i)` = 忽略大小写标志，放在正则最前面，同时匹配 `WRN`、`wrn`、`Warn`
- `([A-Za-z]+)` 只取英文字母，避免吞掉后面的逗号

## 进阶技巧

### 匹配引号内的内容

```
"([^"]+)"
```

- `[^"]+` = 一个或多个非引号字符
- 匹配 `"山风的荆冕"` → 提取 `山风的荆冕`

### 匹配「冒号后的一切」

日志里最常见的格式是 `标签: 内容`，提取内容：

```
:\s*(.+)
```

### 用 (?m) 让 ^ $ 匹配行首行尾

默认 `^` 只匹配整段文本开头，`$` 只匹配结尾。加 `(?m)` 可让它们匹配每一行的首尾：

```
(?m)^探索派遣：.+$
```

## 调试建议

1. 先用**匹配正则**过滤出你要的行，提取正则留空，确认过滤正确
2. 再填**提取正则**，用 `()` 包住你想提取的部分
3. 用规则旁的 🐛 调试按钮粘贴日志行，即时验证结果
4. 如果提取结果多了/少了，检查 `+` 和 `*` 的贪婪问题，试试 `+?` 或 `*?`
