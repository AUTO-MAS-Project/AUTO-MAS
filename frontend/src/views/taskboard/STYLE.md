# 任务台样式规范

适用于 `src/views/taskboard/` 下全部视图：进行中、已达成、已归档、每周任务、版本主线。

## 1. 定位

任务台是打卡与优先级管理工具，不是展示页。判断标准只有三条：同一类卡片在什么位置放什么信息永远一致；扫描一屏能比较出哪个任务更急；状态只由一处表达，不重复着色。

风格取向是「有秩序的卡片网格」：统一尺寸、细描边、克制圆角、悬停轻微抬起。允许从便当盒布局借用统一间隙、圆角、比例和悬停反馈，不允许借用异形卡片、渐变、彩色卡片底和漂浮阴影。

## 2. Token 契约

全部变量在 `src/styles/taskboardTokens.css` 的 `:root` 声明一次，由 `main.ts` 引入；子组件只消费并保留 fallback。任何组件不得再硬编码这些值。

```css
:root {
  --tb-gap: 16px; /* 卡片网格间隙 */
  --tb-grid: repeat(4, minmax(0, 1fr)); /* 所有面板共用的列模板 */
  --tb-card-radius: 10px;
  --tb-cover-ratio: 2.2; /* 封面宽高比 */
  --tb-card-border: var(--ant-color-border-secondary);
  --tb-card-shadow-hover: 0 4px 14px rgb(0 0 0 / 6%);
  --tb-card-shadow-active: 0 2px 6px rgb(0 0 0 / 5%);
  --tb-chip-shadow: 0 2px 6px rgb(0 0 0 / 10%);
  --tb-tag-bg: color-mix(in srgb, var(--ant-color-bg-container) 60%, transparent);
}
```

颜色、背景、文字一律取 `--ant-*`，且只允许 `useTheme.ts` 里定义过的名字。禁止 `#hex`、禁止 Tailwind 色板（`zinc`/`slate` 等）、禁止新增页面私有色阶。

## 3. 页面骨架

```text
页面标题 32/700 + 数据更新时间 12/secondary + 刷新按钮
第一行：搜索 + 条数
第二行：游戏筛选小卡（名称 + 活动数）+ 编辑游戏（跟在游戏后面，虚线胶囊 + 加号）
第三行：页签小卡（图标 + 名称 + 计数），可换行
卡片区：没有统一内容面板，卡片各自成层
  区块间距 24，区块标题 16/700 + 计数 12/secondary
  卡片网格：grid-template-columns: var(--tb-grid)，gap 16；1280/900/600 三档降为 3/2/1 列
```

页面最大宽度 1600px 居中；页边距由全局布局提供，任务台内部只用 16 与 24，不引入第三档间距。卡片高度由内容决定，不预留空行；同一行允许一行以内的自然高度差，不做等高拉伸。

筛选小卡与页签小卡是胶囊形（`border-radius: 999px`，16/28 字号行高，内边距 6px 18px，实际高度 42px）：未选中为 `--app-background-card-bg` 表面 + `--ant-color-border-secondary` 描边 + 正文色文字，选中态为实心 `--ant-color-primary` + 白字（计数转 80% 白）。「编辑游戏」跟在游戏筛选后面，同样 42px，用虚线描边和加号与筛选项区分。三行之间留 20px。页签顺序固定为 进行中 / 已达成 / 已归档 在左，每周任务与版本主线用 `margin-left: auto` 顶到页签行最右端。游戏筛选小卡在游戏名与任务数之间放一个 5px 圆点（`--ant-color-primary`，选中态转 80% 白）作为分隔，不用文字符号。

内容容器 `.tb-body` 不提供表面（无背景、无圆角内边距），筛选小卡、页签小卡与卡片各自使用 `--app-background-card-bg`，遵循 `appearanceSurfaces.css`「一个区域只叠一层表面」的约定：同一块背景不叠加两层半透明白。

## 4. 卡片解剖

进行中、已达成、已归档共用同一个卡片组件（`TaskboardCard`），只有状态带不同。

```text
┌───────────────────────────────────┐
│ 封面 aspect-ratio 2.2              │  object-fit: cover，缺图保留占位底色
├───────────────────────────────────┤
│ 游戏名 a-tag 32px/中性           │
│ 标题（最多 2 行，16/600）            │
│ 描述（两行槽，最多 2 行，左对齐）     │
│ 起止时间（一行，12/tertiary）        │
│ 倒计时 天/时/分（仅进行中）          │
│ 进度条 / 状态带                     │
│ [状态标签 32px]      [操作按钮 32px] │
└───────────────────────────────────┘
```

- 卡片内边距 12px 14px；内容纵向 gap 8px。
- 标题最多 2 行（常规 1 行）；描述区固定两行高度，描述最多 2 行，单行描述在槽内垂直居中且始终左对齐。卡片高度由内容决定，网格 `align-items: start`，不拉伸。
- 没有描述时用「正在进行中」占位、转 tertiary 色；占位与两行描述区同高、左对齐并垂直居中。已归档卡片改用「已结束」占位。
- 游戏名、状态标签、完成按钮统一 32px 高；游戏名与状态标签用 `--tb-tag-bg`（60% 容器表面 + 40% 透明）、`--ant-color-border-secondary` 描边和主文字色，不使用主色填充，主色只保留给完成按钮、选中页签和进行中的 5px 状态圆点。
- 已归档卡片把「已结束」标签放在顶部，与游戏名同一行（左游戏名、右标签），底部不放状态标签。
- 描述最多 2 行（超长截断），悬停用 `a-tooltip` 显示全文；卡片高度由内容决定，不强制同状态等高。
- 起止时间合成一行 `开始 – 结束`；已完成卡片在其下追加一行「完成于」12/600 text-secondary。
- 倒计时 3 格天/时/分，只有进行中与即将结束出现，抽成独立组件 `TaskCountdown`。分钟级时钟由 `useCountdownClock` 提供（模块内单例 + 引用计数，最后一个订阅者卸载即停表），只有倒计时组件订阅它——页面与卡片不参与刷新，也不复用驱动活动源的 `nowTs`。
- 已完成与已结束用居中状态带替代进度条槽位：已完成是「✓ 已完成 / 点击可撤销已达成，进入进行中」，整块可点击撤销，撤销入口只此一处；已结束是「已归档 N 天后删除」。
- 操作区 min-height 32，左侧放状态标签、右侧放完成按钮。
- 封面缺图时不塌陷：`.tb-cover-wrap` 始终占据封面高度，底色 `var(--ant-color-fill-secondary)`。
- 活动没有配图时回退到该游戏当前版本的封面（`gameMetas` 里的 `cover`），避免卡片顶部只剩一块灰底。
- 卡片本体用 `a-card size="small"`，只允许 `:deep(.ant-card-body)` 调整内边距，不改其它 AntD 内部结构。

## 5. 状态语义

一个任务同一时刻只有一个主状态，只由操作区左侧状态标签和进度条/状态带表达。禁止整卡染色、禁止绿边框 + 红进度条 + 蓝按钮同时表达同一件事。

| 状态 | 判定 | 标签（操作区左侧） | 倒计时 | 主体 | 操作区 |
| --- | --- | --- | --- | --- | --- |
| 进行中 | 未完成且剩余 ≥ 3 天 | 进行中 / 中性 + 主色圆点 | 显示 | 进度条主题主色 | 「完成」primary |
| 即将结束 | 未完成且剩余 < 3 天 | 即将结束 / 中性 + 主色圆点 | 显示 | 进度条主题主色 | 「完成」primary |
| 已完成 | 已勾选且未到期 | 不显示（由状态带承担，避免重复） | 不显示 | 状态带「✓ 已完成 / 点击可撤销已达成，进入进行中」，整块可点击撤销，主题主色 | 不显示（撤销由状态带承担） |
| 已结束 | 当前时间 ≥ 结束时间 | 已结束 / 中性，放在卡片顶部右侧（与游戏名同排） | 不显示 | 状态带「已归档 N 天后删除」 | 不显示 |

进行中的状态标签固定在操作区左侧，完成按钮在右侧；已完成只用居中状态带，不放第二个标签；已归档的「已结束」放在顶部右侧与游戏名同排。同一张卡只出现一次状态。状态标签本身用中性表面/文字，进行中、即将结束用 5px 主色圆点区分，主色只保留给完成按钮、选中项和圆点；已结束同样中性；不使用 AntD 预设色，也不引入 warning/success 这类固定语义色。

阈值只有一个：剩余 3 天（`URGENT_LEFT`）。标签转「即将结束」只改文案，圆点颜色不变，不额外引入警示色。

进度条按最后 30 天线性推进，最小可见 4%，到期 100%。

## 6. 文字层级

| 用途 | 字号/字重 | 颜色 |
| --- | --- | --- |
| 页面标题 | 32 / 700 | `--app-page-title-color` 回退 `--ant-color-text` |
| 区块标题（游戏名、每周汇总、版本段标题） | 16 / 700 | text |
| 版本号 | 20 / 700 | text |
| 卡片标题、每周任务名 | 16 / 600 | text |
| 正文与说明 | 12 | text-secondary |
| 时间、辅助信息 | 12 | text-tertiary |
| 完成时间 | 12 / 600 | text-secondary |

字号只取 12 / 14 / 16 / 18 / 20 / 32；18 仅用于倒计时数字，不出现 15、11 等其它中间值。

## 7. 交互与动效

- 卡片默认只有 1px `--tb-card-border`，无阴影。
- 悬停：描边转 `--ant-color-primary-border`，阴影用 `--tb-card-shadow-hover`，`transform: translateY(-2px)`。
- 按压：`transform: translateY(0)`，阴影收回。
- 过渡只列具体属性（`border-color`、`box-shadow`、`transform`），时长 `--tb-motion-fast`，缓动 `--tb-motion-ease`；禁止 `transition: all`。
- 不做悬停放大。密集网格里缩放会引起相邻卡片重绘，扫读时也会误判尺寸变化。
- 可点击卡片（每周任务网格卡、版本节点、列表行）必须有 `role="button"`、`tabindex="0"`、Enter/Space 触发，并有可见焦点环：`outline: 2px solid var(--ant-color-primary); outline-offset: 2px`。
- 按钮沿用 AntD：完成用 `type="primary"` + `loading`，撤销用默认按钮 + `loading`，未就绪用 `disabled`；同一区域只保留一个主按钮。
- 筛选小卡、页签小卡、主页「查看全部活动」按钮有果冻反馈：悬停 `scale(1.03)`、按下 `scale(0.96)`，缓动 `cubic-bezier(0.34, 1.56, 0.64, 1)`，时长 180ms。
- `@media (prefers-reduced-motion: reduce)` 下关闭位移与过渡。

## 8. 主题与表面

- 只用 `--ant-*`，深色无需单独配色。
- 封面灰度、透明度这类滤镜在两种主题下取值相同，不用分支。
- 确实需要区分时，只能在 scoped 样式里用 `:global(html.dark) .tb-xxx`。
- 禁止 `@media (prefers-color-scheme)`，禁止 `[data-theme]`、`.light` 之类不存在的钩子。
- 不使用毛玻璃等额外滤镜：背景透明度由外观设置的 `customSurfaceOpacity` 控制，任务台遵循 `appearanceSurfaces.css`「同一区域只叠一层表面」的约定，不叠加新的模糊层或半透明底色。

## 9. 五个视图的差异

| 视图 | 布局 | 封面 | 特有规则 |
| --- | --- | --- | --- |
| 进行中 | 卡片网格，每行最多 4 张，全部铺开 | 2.2:1 | 有倒计时、进度条与完成按钮 |
| 已归档 | 平铺卡片网格，按结束时间从近到远，不分组 | 2.2:1 | 每张卡顶部显示游戏名与「已结束」；状态带显示「已归档 N 天后删除」 |
| 已达成 | 卡片网格，按完成时间倒序 | 2.2:1 | 居中已完成状态带，点击或按钮均可撤销 |
| 每周任务 | 网格，按游戏名排序 | 2.2:1 | 勾选框常驻右上，点击整卡切换；完成后封面灰度 0.7 + 标题转 secondary；不显示进度条与「本周已完成」汇总；工具行只有「编辑每周任务」按钮 + 药丸样式的重置说明（与页签共用说明同样的表面、描边与 999px 圆角），没有排序开关；「编辑每周任务」单独勾选的游戏只影响本页签：全选/清空立即改变勾选，保存后列表按新选择刷新，空列表表示一个都不选并显示空状态；卡片悬停与活动卡一致（描边转主色 + 轻阴影 + 上浮 2px） |
| 版本主线 | 「当前版本」横向小卡 + 按游戏分组的版本卡片时间轴（无详情侧栏） | 2.2:1 | 只收录版本信息稳定的游戏（`VERSION_STORY_GAMES` 白名单）；当前版本小卡按剩余天数升序排列并显示「还有 N 天」；表头只写「点一下标记」，时间轴表头写「最新版在最左，往右滑看更早 · 本地记录说明」，每组显示版本数；卡片点一下即标记/取消，标记后徽标显示「已标记」；已标记状态统一用主题主色（`--ant-color-primary*`） |

已完成一律使用「降饱和 + 勾选」，不允许整卡绿框、绿底或绿色标题。

## 10. 页面状态

- 加载：`a-spin` 容器 `min-height: 240px`，容器有明确高度，不出现零高度居中。
- 空：共享 `NoData` 组件 + 视图语境文案（无进行中任务 / 本周无任务 / 暂无版本记录）。
- 失败：`a-alert type="warning"` + 重试按钮，说明具体来源问题。
- 保存中：按钮 `loading`，同时禁用重复点击。
- 未就绪：按钮 `disabled`，可点击卡片不响应点击。

## 11. 禁止项

以下来自已评估的便当盒风格，与任务台定位或项目规范冲突，不得使用：

- 异形卡片（`col-span` / `row-span`、大小不一的卡片块）。
- 页面或卡片渐变背景、渐变文字、装饰性背景。
- 彩色卡片底（`*-50` / `*-100` 一类浅色块），颜色只用于状态标签、进度条和按钮。
- 大于 12px 的卡片圆角。
- 悬停放大、30px 以上扩散阴影、任何「漂浮」效果。
- hero 区与超过 32px 的字号。
- 卡片内再嵌卡片（重复列表项与独立工具区除外）。
- 直角、多套圆角并存、`transition: all`、`!important`。

## 12. 已知取舍

- 每周任务卡片当前整卡可点击，但键盘操作只覆盖复选框；整卡 `role`/`tabindex` 暂不处理。
- 已完成封面灰度只在每周任务卡实现（`grayscale(0.7) opacity(0.7)`）；活动卡与版本卡不降饱和。

## 13. 验收清单

- [ ] 每行最多 4 张卡片，1600 宽下正好 4 列，窄屏自动减列。
- [ ] 描述区固定两行高度；标题不超过 2 行，单行描述左对齐并在两行槽内垂直居中。
- [ ] 没有描述的活动显示「正在进行中」占位，占位与两行描述同高、左对齐并垂直居中。
- [ ] 游戏名、状态标签、完成按钮统一 32px；游戏名和状态标签使用 60% 容器表面，主色只留给完成按钮、选中项和进行中圆点。
- [ ] 卡片默认细边框无阴影，悬停只有描边变化 + 轻阴影 + 2px 抬起，无缩放。
- [ ] 状态只由操作区左侧标签和进度条/状态带表达，没有整卡染色；「即将结束」与进度条变色同一时刻发生。
- [ ] 倒计时只在进行中/即将结束出现，三格宽度均分，分钟级刷新只更新倒计时，不影响列表滚动与筛选。
- [ ] 全部颜色来自 `--ant-*`，`grep` 不到新增 `#hex` 和 Tailwind 色名。
- [ ] 亮色与暗色都检查过，无低对比文字，无硬编码白底。
- [ ] 间距使用 8 / 16 / 20 / 24，圆角按用途使用 6 / 10 / 999。
- [ ] 720px 宽下网格自动单列，工具条换行，无横向溢出。
- [ ] 加载、空、失败、保存中、禁用五种状态都有明确呈现。
- [ ] 筛选胶囊与活动卡可用 Tab 聚焦、Enter 触发；每周任务卡当前只保证复选框键盘可达。
- [ ] `prefers-reduced-motion` 下无位移过渡。
