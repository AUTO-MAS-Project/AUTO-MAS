## #185 — 打开配置文件夹

### 冗长版（应避免）

含：涉及页面表、实现要点、Electron IPC、边界条件、参考代码、验收 checkbox 等。

### 精简版（推荐）

```markdown
## 背景

脚本设置会把各用户的配置存到按 UUID 区分的目录。编辑页只能拉起配置程序，无法一键打开对应文件夹，手动找路径很麻烦。

## 期望

- 在用户编辑页（已有 userId 时）增加「打开配置文件夹」
- 点击后在系统文件管理器中打开该用户的配置目录
- 目录尚不存在时自动创建再打开
- 覆盖通用 / MAA / SRC / MaaEnd 等脚本类型的用户编辑页
```

## #186 — 游戏进程

### 精简版（推荐）

多个功能 → 分点 + 小标题。

```markdown
## 背景

内置游戏管理会在任务中自动启动 PC 游戏或通过协议拉起。游戏已运行时再次启动，常弹出「已在运行」类窗口，可能挡住自动化导致任务失败。部分游戏（如鸣潮）安装路径很深，用户难以在设置里精确选到 exe 或进程名。

## 期望

### 1. 避免重复启动

- 启动前检测目标游戏是否已在运行
- 已运行则跳过启动，任务侧仍能识别并管理该进程

### 2. 降低游戏配置门槛

- 提供主流游戏预设（如鸣潮、星铁等）
- 用户选择安装根目录后，按文件夹名等规则自动匹配 exe / 进程，无需手写进程名或翻找深层路径

**范围**：通用脚本、MaaEnd 的游戏管理优先。
```
