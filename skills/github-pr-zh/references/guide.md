# Pull Request 描述规范（完整）

对应 Skill：`github-pr-zh`。

## 写什么

- **摘要**：1～4 条 bullet，说明本 PR 已实现的功能或修复（用户/维护者视角）。
- **关联**（若有）：`Closes #123` 或 `相关 #123` 一行。

## 不写什么

- 长篇背景复述（issue 里已有则不必重复）
- 详细技术方案、文件清单、重构动机长文
- 默认不写 Test plan，除非维护者或仓库规范明确要求

## 篇幅

- 理想：**约 50～200 字**。

## 模板

```markdown
## 摘要

- [实现了什么]

Closes #123
```
